# Outdoor Activity Planner

Documentazione ufficiale del progetto **Outdoor Activity Planner**.

## Panoramica

L'applicazione ha l'obiettivo di supportare la pianificazione di attivita outdoor, offrendo agli utenti strumenti per organizzare esperienze, consultare funzionalita dedicate e gestire il proprio profilo.

## Contenuti disponibili

- **Autenticazione**: descrive la registrazione utente tramite email/password e Google, la persistenza su Firestore e i test automatici associati.

- **Gestione mappa**: il modulo di gestione della mappa, i componenti coinvolti e le API utilizzate.
